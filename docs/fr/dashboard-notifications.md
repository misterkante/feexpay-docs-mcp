# Notifications

Restez informé des actualités de la plateforme

Le menu **Notifications** affiche les communications générales envoyées par FeexPay à l'ensemble des marchands. Il ne s'agit pas de notifications personnelles liées à vos transactions, mais d'informations diffusées à toute la communauté marchande.

![Interface Notifications — onglets et panneau de lecture](https://docs.feexpay.me/notifications/notifications_overview.png)

### Interface

La page est divisée en deux parties :

-   **Liste (gauche)** : affiche toutes les notifications reçues. Lorsqu'il n'y en a aucune, le message _"Aucune notification / Rien à afficher"_ apparaît.
-   **Détail (droite)** : affiche le contenu de la notification sélectionnée. Sans sélection, le message _"Sélectionnez une notification / Cliquez sur une notification pour la lire"_ s'affiche.

### Onglets de filtrage

| Onglet | Description |
| --- | --- |
| Toutes | Affiche toutes les notifications reçues, lues et non lues. |
| Non lues | Filtre uniquement les notifications que vous n'avez pas encore consultées. |
| Lues | Affiche uniquement les notifications déjà consultées. |

### Contenu des notifications

-   **Incidents et dysfonctionnements** : signalement d'une panne ou d'une interruption de service.
-   **Corrections de bugs** : information sur les correctifs appliqués suite à des anomalies.
-   **Nouvelles fonctionnalités** : annonce des mises à jour et améliorations de la plateforme.
-   **Actualités FeexPay** : informations générales sur l'évolution des services.

**Note :** Ces notifications sont communes à tous les marchands. L'indicateur _"Tout est lu"_ en haut de la page confirme qu'aucune notification n'est en attente de lecture.
