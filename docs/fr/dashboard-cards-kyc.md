# Cards KYB

L'onglet **Cards KYB** vous permet de remplir les informations nécessaires pour accepter les paiements par carte bancaire sur votre boutique. Cette fonctionnalité est essentielle pour élargir vos moyens de paiement et offrir plus de flexibilité à vos clients.

### Pour activer les paiements par carte bancaire:

1.  Connectez-vous à votre tableau de bord FeexPay
2.  Cliquez sur le menu **Cards KYB**
3.  Remplissez le formulaire avec vos informations personnelles et professionnelles
4.  Téléchargez les documents requis (pièce d'identité, justificatif de domicile, etc.)
5.  Soumettez votre demande pour validation
6.  Attendez la confirmation de validation par email

![Formulaire Cards KYB](https://docs.feexpay.me/dashboard/dashboard_new.png)

### Documents requis:

-   Pièce d'identité valide (carte nationale, passeport ou permis de conduire)
-   Justificatif de domicile récent (facture d'électricité, eau, internet)
-   Documents juridiques pour les entreprises (statuts, registre de commerce)
-   Relevé bancaire pour vérification du compte
-   Photo récente du titulaire du compte (pour vérification)

### Types de cartes acceptées:

![VISA](https://docs.feexpay.me/card/brands/visa.svg)

Cartes de débit et crédit VISA avec 3DS

![MASTERCARD](https://docs.feexpay.me/card/brands/mastercard.svg)

Cartes de débit et crédit Mastercard avec 3DS

#### Important:

-   Le processus de validation peut prendre 2-5 jours ouvrables
-   Toutes les informations doivent être exactes et à jour
-   Les documents doivent être clairs et lisibles
-   Une fois validé, vous ne pouvez pas modifier certaines informations

### Avantages de l'activation:

-   Augmentez vos taux de conversion avec plus de moyens de paiement
-   Acceptez les paiements internationaux
-   Sécurité renforcée avec la technologie 3D Secure
-   Transactions traitées en temps réel
-   Suivi détaillé des transactions par carte dans votre tableau de bord
