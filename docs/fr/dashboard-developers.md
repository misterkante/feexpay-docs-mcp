# Développeurs

La création d'un compte FeexPay vous attribue une clé API ainsi qu'un identifiant que vous pouvez utiliser afin d'intégrer une méthode de paiement avec FeexPay sur vos sites web ou applications. Ce menu vous permet de consulter votre clé API et votre identifiant. Il faudrait veiller à les conserver secrets. Vous ne devez les communiquer à personne.

### Pour consulter votre clé API:

1\. Cliquez sur le menu **Développeurs**

2\. Consultez la clé de votre api en cliquant sur le bouton **oeil**

3\. Vous pouvez aussi réinitialiser ou copier votre clé dans le menu d'action.

![Consulter la clé API](https://docs.feexpay.me/developers/action_api_new.png)

### Pour consulter votre identifiant:

Cliquez sur l'onglet **Identifiant**.

![Onglet Identifiant](https://docs.feexpay.me/developers/identi_new.png)

### Régénérer la clé API

Si vous suspectez que votre clé API a été compromise ou si vous souhaitez simplement la renouveler par sécurité, vous pouvez la régénérer. Attention : l'ancienne clé cessera immédiatement de fonctionner et vous devrez mettre à jour votre code avec la nouvelle clé.

1\. Cliquez sur le menu **Développeurs**.

2\. Cliquez sur le bouton **oeil** pour afficher votre clé API.

3\. Dans le menu d'action, cliquez sur **Réinitialiser**.

4\. Confmez la régénération dans la fenêtre de confirmation.

5\. La nouvelle clé API s'affiche immédiatement. Copiez-la et mettez à jour votre code.

![Régénérer la clé API](https://docs.feexpay.me/developers/regenerate_api_key.png)

Intégrer FeexPay dans votre application React Js ou votre site web WordPress, JavaScript, PHP.
