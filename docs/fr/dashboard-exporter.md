# Exporter

Téléchargez vos données au format Excel ou CSV

Le menu Exporter vous permet de télécharger l'historique de vos transactions (collectes) et de vos reversements effectués depuis le dashboard au format CSV ou Excel, pour un suivi comptable ou analytique.

![Interface Exporter — formulaire de sélection](https://docs.feexpay.me/exporter/exporter_overview.png)

### Comment exporter vos données

1.  Rendez-vous dans le menu Exporter depuis le menu latéral.
2.  Sélectionnez la période souhaitée en choisissant une date de début et une date de fin.
3.  Choisissez le type de données à exporter :
    -   Collectes — toutes les transactions de type payin (paiements reçus)
    -   Reversements — tous les reversements effectués depuis le dashboard (manuels)
    -   Payout API — toutes les transactions effectuées via l'API Payout
4.  Sélectionnez le format de fichier : Excel ou CSV.
5.  Cliquez sur le bouton Exporter pour lancer la génération du fichier.

![Export en cours — message de confirmation](https://docs.feexpay.me/exporter/exporter_processing.png)

### Télécharger le fichier

Une fois l'export terminé, un message de confirmation s'affiche. Vous pouvez alors télécharger votre fichier en cliquant sur le bouton Télécharger.

![Export terminé — bouton Télécharger](https://docs.feexpay.me/exporter/exporter_download.png)

**Note :** Les fichiers exportés contiennent les informations de chaque transaction (référence, montant, réseau, statut, date, numéro de téléphone, etc.) et peuvent être importés dans un tableur (Excel, Google Sheets) pour analyse comptable.

**Distinction :** Vous pouvez exporter les collectes (payins), les reversements manuels du dashboard, ainsi que les transactions effectuées via l'API Payout depuis ce menu.
