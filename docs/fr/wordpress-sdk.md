# WordPress (WooCommerce)

[Télécharger le plugin WordPress](https://wordpress.org/plugins/feexpay/). Il est conçu afin de faciliter l'utilisation de FeexPay sur votre site WooCommerce. Voici quelques étapes pour la configuration de FeexPay sur votre site WordPress.

### 1\. Télécharger le plugin

[Télécharger ici](https://wordpress.org/plugins/feexpay/) et installer le plugin sur votre site WordPress. Assurez‑vous d'avoir installé et activé **WooCommerce** au préalable.

### 2\. Uploader puis activer votre plugin

1.  Paramétrer votre plugin.
2.  Cliquer sur **Settings**. Vous pouvez alors configurer FeexPay grâce à ce formulaire. Cocher la case **Activer Feexpay Paiement** pour activer FeexPay sur votre site. Remplissez le formulaire selon vos préférences avec un titre et une description. Vous devez aussi fournir votre **clée d'api** et votre **id de magasin**
