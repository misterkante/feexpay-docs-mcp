# F-QR Code

La fonctionnalité F-QR Code de FeexPay fonctionne de la même façon que FeexLink. La différence est que vous précisez le montant à l'avance ainsi que le pays et le réseau sur lequel vous souhaitez collecter. Une fois créé, vous obtenez un QR code scannable que vous pouvez télécharger et afficher sur une pancarte, un tableau, une table ou tout autre support physique.

Pour l'utiliser, suivez ces quelques étapes.

1\. Cliquez sur le menu **F-QR Code** dans le menu latéral de votre dashboard.

2\. Cliquez sur le bouton **Créer un QR Code**.

![Bouton Créer un QR Code](https://docs.feexpay.me/quicklinks/quicklink_annote_new.png)

3\. Remplissez le formulaire en précisant le montant, le pays et le réseau sur lequel vous souhaitez collecter, la description, le lien de retour et l'image ou logo.

4\. Cliquez sur le bouton **Suivant** pour finaliser la création.

![Formulaire F-QR Code — montant et pays](https://docs.feexpay.me/quicklinks/quicklink_form1_new.png)

Votre QR Code est créé. Vous pouvez le **télécharger** sous forme d'image pour l'imprimer ou l'afficher sur une pancarte, un tableau, une table, etc. Utilisez le bouton **Copier** pour copier le lien ou consultez les détails via le bouton **œil**.

![Actions sur le QR Code — télécharger, copier, consulter](https://docs.feexpay.me/quicklinks/actions_quicklink_new.png)
