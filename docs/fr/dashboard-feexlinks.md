# FeexLink

FeexLink est une fonctionnalité qui permet de créer des liens de paiements pour vos produits ou service.

Pour l'utiliser, c'est très facile. Suivez ces quelques étapes.

1\. Cliquez sur le menu **FeexLink** dans le menu latéral de votre dashboard.

2\. Cliquez sur le bouton **créer un nouveau lien**.

![Créer un nouveau lien](https://docs.feexpay.me/feexlinks/feexlink_annote_new.png)

3\. Remplissez le formulaire qui apparaît en fournissant le prix et la description de votre produit ou service.

4\. Cliquez sur le bouton **suiv**.

![Formulaire prix et description](https://docs.feexpay.me/feexlinks/feexlink_form1_new.png)

5\. Remplissez convenablement le formulaire qui apparaît.

6\. Cliquez sur le bouton **suiv**.

![Formulaire détails](https://docs.feexpay.me/feexlinks/feexlink_form_2_new.png)

7\. Choisissez un fichier de l'Image ou logo du produit/service.

8\. Cliquez sur le bouton **suiv**.

![Upload image](https://docs.feexpay.me/feexlinks/feexlink_form3_new.png)

Vous venez juste de créer un lien de paiement. Cliquez sur le bouton **oeil** pour consulter les détails de votre lien ou sur le bouton **Copier** pour copier le lien. Vous avez la possibilité de consulter votre lien, de le supprimer grâce au menu d'action.

![Actions sur le lien](https://docs.feexpay.me/feexlinks/actions_feexlink_new.png)
