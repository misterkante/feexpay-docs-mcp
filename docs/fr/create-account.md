# Créer un compte

Avant toute opération avec FeexPay, vous devez disposer d'un compte validé.

### Nouveau compte

Pour créer un nouveau compte, c'est très facile.

1.  Cliquer sur le lien suivant : [Créer un nouveau compte](https://app-v2.feexpay.me/signup/)
2.  Cliquer sur le bouton **Démarrer**

![Créer un compte](https://docs.feexpay.me/create_account/demarer_new.png)

3.Remplir le formulaire suivant avec votre nom, prénom et votre adresse mail et le nom de votre entreprise.

4.Cliquer ensuite sur le bouton **S'Inscrire**.

![Créer un compte](https://docs.feexpay.me/create_account/form_compte_1_new.png)

5.Consulter votre boîte mail pour valider votre inscription. Cliquer sur le lien de validation.

![Créer un compte](https://docs.feexpay.me/create_account/mail_valider_new.png)

6.Remplir le formulaire avec votre mot de passe.

![Créer un compte](https://docs.feexpay.me/create_account/password_valider_new.png)

8.Cliquer sur la case à cocher **J’accepte les termes et conditions** pour accepter les Conditions Générales d’Utilisation.

9.Cliquer sur le bouton **Terminer**.
