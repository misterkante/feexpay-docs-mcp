# Validation de compte

La validation de compte est une étape importante pour exploiter en production les services de FeexPay. Elle permet de lutter contre la fraude et de maintenir une certaine sécurité par rapport à l’identité et à l’activité du marchand. Pour ce faire, veillez suivre les étapes suivantes:

1.  Connecter vous à votre **compte**
2.  Cliquer sur le bouton **Valider mon compte**.

![Créer un compte](https://docs.feexpay.me/validate_account/valider_ou_sandbox.png)

3.Remplir le formulaire avec vos informations.

![Créer un compte](https://docs.feexpay.me/validate_account/form_validation_1.png)

4.Cliquer sur le bouton **Suivant**.

5.Sélectionner le type d'entreprise et sélectionner la catégorie de votre entreprise.

![Créer un compte](https://docs.feexpay.me/validate_account/selectionner_type_entreprise.png)

6.Remplir le formulaire avec les informations administratives demandées selon le type d'entreprise que vous aurez choisi.

![Créer un compte](https://docs.feexpay.me/validate_account/formulaire_administratif.png)

7.Cliquer sur le bouton **Continuer**.

8.Vous recevrez un message de confirmation de demande.

![accountValidation.images.final\_step](https://docs.feexpay.me/validate_account/final_step.png)
