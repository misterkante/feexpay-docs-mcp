# Shops

Manage your shops and points of sale

The Shops menu allows you to create and manage your FeexPay shops. Each shop has a unique reference and can collect payments independently — ideal for distinguishing multiple activities or websites on the same account.

![Interface Boutiques — liste des boutiques actives et inactives](https://docs.feexpay.me/boutiques/boutiques_overview.png)

### Overview

At the top of the page, three counters give you a quick summary:

N

Total shops

N

Active shops

N

Inactive shops (deactivated)

### Create a shop

1.  Go to the Shops menu from the sidebar.
2.  Click the + Create shop button at the top right.
3.  Enter the shop name and required information.
4.  Confirm — the shop appears in the Active tab.

### Actions

| Column | Description |
| --- | --- |
| Name | Shop name and its status (Active / Inactive) |
| Reference | Unique shop identifier (used in API calls) |
| Creation date | Date the shop was created |
| Actions | Modify and Deactivate buttons |

### Modify a shop

Click the Modify button on the shop's row to update its information (name, settings, etc.).

### Deactivate a shop

Click the Deactivate button to deactivate an active shop. The shop moves to the Inactive tab and can no longer receive payments.

**⚠️ Important :** A deactivated shop cannot be reactivated by the merchant.
