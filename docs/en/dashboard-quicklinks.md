# F-QR Code

FeexPay's F-QR Code feature works the same way as FeexLink. The difference is that you specify the amount upfront, as well as the country and network you want to collect on. Once created, you get a scannable QR code image that you can download and display on a sign, board, table or any other physical medium.

To use it, follow these steps.

1\. Click the **F-QR Code** menu in the dashboard sidebar.

2\. Click the **Create a QR Code** button.

![Create QR Code button](https://docs.feexpay.me/quicklinks/quicklink_annote_new.png)

3\. Fill in the form by specifying: the amount, the country and network to collect on, description, return link, and image or logo.

4\. Click **Next** to complete the creation.

![F-QR Code form — amount and country](https://docs.feexpay.me/quicklinks/quicklink_form1_new.png)

Your QR Code is created. You can **download** it as an image to print or display on a sign, board, table, etc. Use the **Copy** button to copy the link, or view the details using the **eye** button.

![QR Code actions — download, copy, view](https://docs.feexpay.me/quicklinks/actions_quicklink_new.png)
