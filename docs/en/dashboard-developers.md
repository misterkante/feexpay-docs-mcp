# Developers

Creating a FeexPay account assigns you an API key and an identifier that you can use to integrate a payment method with FeexPay on your websites or applications. This menu allows you to view your API key and your identifier. You should make sure to keep them secret. You must not communicate them to anyone.

### To view your API key:

Click on the **Developers** menu

View your api key by clicking on the **eye** button

You can also reset or copy your key in the action menu.

![View API key](https://docs.feexpay.me/developers/action_api_new.png)

### To view your identifier:

Click on the **Identifier** tab.

![Identifier tab](https://docs.feexpay.me/developers/identi_new.png)

### Regenerate API key

If you suspect your API key has been compromised or if you simply want to renew it for security, you can regenerate it. Warning: the old key will immediately stop working and you will need to update your code with the new key.

1\. Click on the **Developers** menu.

2\. Click on the **eye** button to display your API key.

3\. In the action menu, click on **Reset**.

4\. Confirm the regeneration in the confirmation window.

5\. The new API key is displayed immediately. Copy it and update your code.

![Regenerate API key](https://docs.feexpay.me/developers/regenerate_api_key.png)
