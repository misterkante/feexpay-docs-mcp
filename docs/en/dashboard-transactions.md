# Collections

Manage all your collections

The Collections menu lists all your payin transactions (received payments). You can search, filter and export your collections using different criteria.

![Interface Collectes — recherche et filtres](https://docs.feexpay.me/collectes/collectes_overview.png)

### Search by criteria

Use the Choose a criteria selector, then enter the value to search for in the search bar. Available criteria are:

-   Amount — search by transaction amount
-   Number — payer's phone number
-   FeexPay Reference — internal transaction identifier
-   Merchant Reference — reference you provided when creating the transaction
-   Operator Ref — reference generated by the mobile money operator
-   Description — description associated with the transaction
-   Callback Info — callback data linked to the transaction

### Advanced filters

Combine multiple filters to refine your results:

| Filter | Description | Possible values |
| --- | --- | --- |
| Start date / End date | Collection period | Date picker |
| Status | Transaction status | Success, Failed, Pending |
| Network | Mobile money operator used | MTN, Moov, Orange, Wave… |
| Type | Payment origin | All types, FeexPage, FeexLink, Payment |

### Available actions

-   Refresh — reloads results based on current filters.
-   View all transactions — displays all your collections without filter, to view the latest received transactions.
-   Export — downloads the search results in Excel or CSV format for external or accounting purposes.

**Note :** When no filter is selected, the page displays the message "Use the filter bar above to find transactions.". Click View all transactions to display all collections.
