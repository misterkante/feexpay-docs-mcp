# Postman Collection

Test the FeexPay API easily with Postman

We provide a complete Postman collection with all FeexPay API endpoints. Import it into Postman to quickly test all features.

### Download Collection

The Postman collection includes all endpoints with request and response examples.

 [Download JSON Collection] 

### Installation Instructions

1

#### Download and Install Postman

If you don't have Postman yet, download it from [postman.com/downloads](https://www.postman.com/downloads/)

2

#### Import Collection

1.  Open Postman
2.  Click 'Import' in the top left
3.  Select the downloaded JSON file
4.  Click 'Import'

3

#### Configure Environment

Create a new environment and add these variables:

-   `base_url`https://api-v2.feexpay.me
-   `fp_api_key`Your FeexPay API key (starts with fp\_)
-   `shop`Your shop identifier

4

#### Test Endpoints

Select a request from the collection and click 'Send' to test it. Environment variables will be automatically used.

### Collection Content

#### Payin

All collection requests by country

#### Payout

All payout requests
