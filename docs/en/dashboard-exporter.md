# Export

Download your data in Excel or CSV format

The Export menu allows you to download the history of your transactions (collections) and manual dashboard payouts in CSV or Excel format, for accounting or analytical purposes.

![Interface Exporter — formulaire de sélection](https://docs.feexpay.me/exporter/exporter_overview.png)

### How to export your data

1.  Go to the Export menu from the sidebar.
2.  Select the desired period by choosing a start date and an end date.
3.  Choose the type of data to export:
    -   Collections — all payin transactions (received payments)
    -   Payouts — all manual payouts made from the dashboard
    -   Payout API — all transactions made via the Payout API
4.  Select the file format: Excel or CSV.
5.  Click the Export button to start generating the file.

![Export en cours — message de confirmation](https://docs.feexpay.me/exporter/exporter_processing.png)

### Download the file

Once the export is complete, a confirmation message appears. You can then download your file by clicking the Download button.

![Export terminé — bouton Télécharger](https://docs.feexpay.me/exporter/exporter_download.png)

**Note :** Exported files contain the information of each transaction (reference, amount, network, status, date, phone number, etc.) and can be imported into a spreadsheet (Excel, Google Sheets) for accounting analysis.

**Distinction :** You can export collections (payins), manual dashboard payouts, and Payout API transactions from this menu.
