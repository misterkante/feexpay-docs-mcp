# Payout API

Manage your API disbursements

The Payout API menu lists all your payout transactions (disbursements made via API). You can search, filter and export your payouts using different criteria.

⚠️

#### IP whitelist required

You have not yet added an IP address to the whitelist. Without this configuration, you will not be able to make payouts via the API. Go to the IP Address menu to add your authorized IP addresses.

![Interface Payout API — recherche et filtres](https://docs.feexpay.me/payout-api/payout_api_overview.png)

### Search by criteria

Use the Choose a criteria selector, then enter the value to search for in the search bar. Available criteria are:

-   Amount — search by payout amount
-   Number — beneficiary's phone number
-   FeexPay Reference — internal payout identifier
-   Merchant Reference — reference you provided when creating the payout
-   Operator Ref — reference generated by the mobile money operator
-   Description — description associated with the payout
-   Callback Info — callback data linked to the payout

### Advanced filters

Combine multiple filters to refine your results:

| Filter | Description | Possible values |
| --- | --- | --- |
| Start date / End date | Payout period | Date picker |
| Status | Payout status | Success, Failed, Pending |
| Network | Mobile money operator used | MTN, Moov, Orange, Wave… |

### Available actions

-   Refresh — reloads results based on current filters.
-   View all transactions — displays all your payouts without filter, to view the latest disbursements.
-   Export — downloads the search results in Excel or CSV format for external or accounting purposes.

**Note :** When no filter is selected, the page displays the message "Use the filter bar above to find transactions.". Click View all transactions to display all payouts.

**Export :** You can export Payout API transactions from this page or from the Export menu by selecting the Payout API option.
